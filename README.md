# DealAgent Labs Starter Kit

Autonomous AI agents for commercial real estate deal sourcing.

## Overview
This kit provides:
- Prompt templates for deal screening agents
- Sample Python code for public records monitoring and scoring
- Workflow diagrams for end-to-end pipeline
- Integration patterns for CRM and outreach

## Quick Start
1. Clone this repo
2. Set up API keys for data sources (ATTOM, Reonomy, etc. - mock in sample)
3. Run `python src/agent.py` with your buy-box criteria
